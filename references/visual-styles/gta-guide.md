## Deux familles visuelles
1. **Walkthrough gameplay** (ref09, ref10, ref11, ref12) : capture de jeu verticale, caméra 3e
   personne dans le dos du perso. Plans types : marche vers le lieu, **carte du jeu** (menu pause,
   zoom sur la zone, pin), interaction (prompt « SAISIR LE CODE »), **gros plan clavier/digicode**
   avec le code en sous-titre, coffre ouvert, butin, retour en véhicule pendant le CTA.
2. **Trailer + motion design** (ref13) : footage officiel (trailers) recadré en 9:16 + **overlays
   UI** inventés : cartes « vitrées » (fond sombre translucide, bord néon rose/cyan, barres
   segmentées ÉQUIPEMENT / DIFFICULTÉ / ARGENT / MARCHANDISE), bulles d'icônes circulaires reliées
   par des flèches (diamant → blanchiment), compteur d'argent vert néon `$0 → $1 000 000`.
   → C'est la famille réalisable **sans posséder le jeu** : c'est notre format principal tant que
   l'utilisateur ne fournit pas ses propres captures de gameplay.

## Typographie (zooms pleine résolution)
- **@adrgta** : grotesque **condensée ultra-grasse, italique, MAJUSCULES** (proche Anton/Bebas
  Neue penchée de ~10°), blanc, ombre portée sombre courte et douce. **Mot-clé en jaune**
  (`#F5C518` env., « LÉGENDAIRE »). Mots de liaison parfois en gris semi-transparent (« ASSEZ
  LIMITÉ ») = hiérarchie. 1–3 mots.
- **@gta6alerte_** : sans-serif géométrique **Bold, casse phrase** (proche Poppins/Montserrat 700),
  ombre légère. Codes et montants espacés (`0 0 7 2`, `11.000$`) = lisibles comme un code.
- **@mielpops** : Poppins SemiBold **italique minuscules**.
- Toujours **centré horizontalement**, une seule ligne, hors des zones d'UI TikTok (droite et bas).

## Animations
| Élément | Observation (30 fps) |
|---|---|
| Ouverture | **Zoom-blur radial** sur 6 frames (0,2 s) qui se résout sur le plan du hook + son whoosh. |
| Sous-titre | Apparition **cut** sur le mot (pas d'animation longue) ; parfois sortie de flou ~3 frames. |
| Compteur d'argent | Montée ease-out ~1 s (`$175 139` à f5 → `$1 000 000` à f~20), glow vert. |
| Coupes | Cut sec sur le mot ; micro-plans 0,25–0,3 s pour les accents ; pas de fondu. |
| Cartes UI | Apparition en fondu + léger slide, barres qui se remplissent segment par segment. |
| CTA fin | Bouton « S'abonner » (pilule blanche) → curseur main → clic → « Abonné » (pilule rouge) ; ou pastille de profil + « + » qui devient ✓. |
| Logo de chaîne | Bug permanent en haut (gauche ou droite), petit, blanc. |

## Structure narrative (constante sur les 5)
| TC | Bloc | Exemple (paraphrase, pas de copie) |
|---|---|---|
| 0–3 s | **Hook promesse** | « Tu savais que dans GTA 6… », « Le secret sur GTA 6… », « Voici comment gagner 1 M$ » |
| 3–8 s | Enjeu / récompense | arme légendaire, X $, véhicule rare |
| 8–50 s | **Étapes guidées** | carte → lieu précis → action → code → coffre ; un plan par étape |
| 50–58 s | Récompense + bonus | montant, deuxième secret, astuce de sécurité |
| 58–62 s | **CTA** | « abonne-toi pour d'autres astuces », « like », « dis-moi en commentaire » |

## Sound design (mesuré, pas écouté)
- Voix off française rapide, **dominante**, commence à t = 0 (pas d'intro musicale).
- Musique avec sub continu sous la voix (bande < 80 Hz permanente au spectrogramme ref13).
- Transitoires aigus (5–10 kHz) aux moments du compteur → SFX type « cash/tick » probables.
- Whoosh d'ouverture sur le zoom-blur.

## Réutilisable vs à ne pas copier
- **Principes réutilisés** : rythme 1,5 s/plan, sous-titre 1–3 mots à 77 %, mot-clé coloré,
  hook-promesse, étapes carte → lieu → action → récompense, overlays UI vitrés, compteur, CTA animé.
- **À ne pas reprendre** : logos/pseudos des comptes, leurs textes, leur pastille « ADA »,
  leurs captures de gameplay. Nos overlays, notre bug de chaîne et notre CTA sont dessinés par nous.
- **Footage GTA VI** : uniquement des sources réelles (téléchargements officiels Rockstar ou
  captures fournies par l'utilisateur), jamais inventé ni généré. Audio des trailers **toujours
  coupé** (chansons sous licence). Voir `.claude/skills/gta-footage-sourcing/`.
