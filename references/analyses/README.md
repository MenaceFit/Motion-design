# Données d'analyse brutes

Sorties de `tools/analyze_reference.py` (métriques uniquement : métadonnées, coupes, palette,
onsets audio, courbe mouvement/audio). Les images extraites des vidéos de référence (planches
contact, frames) ne sont **pas** versionnées : ce sont des contenus de tiers. Pour les régénérer,
relancer l'outil sur la vidéo source.
